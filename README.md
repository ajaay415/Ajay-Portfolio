# Venkata Ajay Battula — Developer Portfolio

A responsive, futuristic dark portfolio built with HTML, CSS and vanilla JavaScript. No frontend build step or npm dependencies are required.

## Run locally

**Node.js (recommended)**

```bash
node server.js
```

Open http://localhost:3000.

**Optional Flask server**

Install Flask with `python -m pip install flask`, then run:

```bash
python app.py
```

Open http://localhost:5000.

You can also open `index.html` directly in a browser.

## Customize

- Edit `config.js` to update skills and project content.
- Update GitHub and LinkedIn links in `index.html` and `config.js`.
- Update the contact email in `index.html`.

## Notes
