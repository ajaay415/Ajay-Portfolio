# Venkata Ajay Battula — Developer Portfolio

A responsive, dark futuristic portfolio built with plain HTML, CSS and JavaScript. No build step or npm dependencies are required.

## Run locally

**Option 1 — Python**

```bash
python app.py
```

Open http://localhost:5000.

**Option 2 — Node.js**

```bash
node server.js
```

Open http://localhost:3000.

You can also open `index.html` directly in a browser.

## Customize

- Edit `config.js` to update skills and project content.
- Update the GitHub and LinkedIn links in `index.html` and `config.js` if needed.
- Add a real email address or resume link only when you are ready to publish it.

## Notes

- Project cards link to the GitHub profile because individual repository URLs were not provided.
- Project statuses are deliberately conservative; update them as the work progresses.
- No placeholder phone number, email, fake client testimonial, fabricated employer or unverified metric is published.
